2. 账户

账户区展示当前登录身份：

  • 登录名（截图示例为用户显示名）
  • 邮箱（旁有复制图标）
  • 添加账户：再挂一个账号（多账号切换时用）
  • 退出登录：退出当前账号

账号切换 / 登出会影响本机会话与已连接应用；退出前确认没有正在跑、依赖本机授权的任务。

3. 外观

截图中 外观 有三项下拉（以客户端为准）：

控件截图示例取值说明
主题跟随系统也可选浅色 / 深色一类选项（以客户端列表为准）

语言跟随系统可改为跟随系统或指定语言（含简体中文等）

改语言后若部分文案仍英中混排，以当前客户端版本为准；对照官方文档时可用英文标签。

4. 顶部订阅入口（界面可见）

通用页顶部有一块订阅相关卡片（截图文案大意：统一订阅获取 Grok / Cursor / X、共享用量池；已订阅产品可合并）。这是界面上的入口，不是本站的推销——是否出现、文案与按钮（如「开始使用」）随账号与客户端版本变化。

额度、价格与资格请看订阅与资格和设置 · 用量与账单；本站不写具体数字。

5. 截图未见、暂不展开

以下控件在本张通用页截图中未见，官方文档或其它版本可能另有入口，此处不编造：

  • 拼写检查、麦克风、硬件加速、安全密钥等
  • 时区 / Bot 排程相关项（若你客户端有，以本机为准）
  • Auto-review 规则管理（审批相关仍见安全与审批；本机执行主界面在设置 · 电脑）

你要检查什么

  • 登录名与邮箱是否为当前要用的账号；多账号时先确认再操作。
  • 主题 / 语言是否符合习惯（跟随系统还是固定）。
  • 顶部订阅卡片只当入口；用量细节去「用量与账单」或官方订阅页。
